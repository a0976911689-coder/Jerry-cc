# 社群成效診斷工具

當「按讚少、流量低、客人變少」時，用資料找原因，不要用猜的。

## 1. 先要這些資料（截圖即可）
| 平台 | 要的畫面 |
|---|---|
| FB 粉專 | 專業主控板 → 分析 28 天：瀏覽、互動、追蹤；觀眾類型（追蹤者／非追蹤者）；影音素材類型；觀看次數類型 |
| FB 粉專 | 受眾：年齡、性別、**城市** |
| 各平台 | 最近 5～10 則貼文（內容＋讚、留言、分享） |
| 店內 | 每週訂單或營業額，最好附日期 |

拿不到資料就明說拿不到，不要假裝看過。

## 2. 數字怎麼讀
| 現象 | 代表 |
|---|---|
| 瀏覽高、追蹤增加很少 | 有曝光、沒轉換：頁面資訊、行動呼籲、追蹤理由不足 |
| 非追蹤者比例很高 | 觀眾多是陌生人，需要讓第一次看到的人知道「你是誰、在哪、怎麼買」 |
| 某素材類型占比最高 | 多做這一型（例：多張相片） |
| 3 秒觀看多、1 分鐘觀看 0 | 影片太長或開頭沒抓住人，改 10～15 秒 |
| 前一期幾乎為 0、成長倍數極大 | 帳號剛開始經營，不能用來判斷「客人變少」 |
| 實體來客變少 | 先對照 [營業週期]（例：農曆初一十五），區分週期低谷與真正流失 |

轉換率：新增追蹤 ÷ 瀏覽人數，算給對方看。

## 3. 貼文常見問題與改法
| 問題 | 改法 |
|---|---|
| 價目表太長、像傳單 | 主推 1～2 樣，其他放留言 |
| 長網址（含 utm）放內文 | 連結放留言或自己的第二則回覆 |
| 「互追」「漲粉」 | 刪掉，吸引的不是客人 |
| 主圖是小格拼貼 | 第一張改大張實拍（切開、手拿） |
| 每天風格不同 | 固定一種視覺 |
| 名稱不統一 | 固定一個品牌名、一個群組名 |
| 沒用真實故事 | 客人回購、試吃感受，是最強素材 |

## 4. 回報格式
```
【資料】看到什麼、沒看到什麼
【判斷】最可能的原因（標明是推論）
【建議】這週可以做的 3～4 件事
【追蹤】接下來 2～4 週要記的數字
```
