# 每日商品推薦貼文 SOP（多平台）

把「當天照片＋一行品項價格」變成多個平台的貼文、圖卡文字與檢查結果。

## 需要替換的欄位
| 欄位 | 範例（英仔果子行） |
|---|---|
| [品牌名稱] | 英仔果子行 |
| [發文身分] | 小英仔（以賣水果、分享生活的人的口吻） |
| [發文時間] | 每天 07:00 |
| [品項上限] | 5 |
| [字數上限] | 每個平台精華文字 50 字 |
| [平台清單] | Threads、FB 在地社團、IG、LINE 聊天群 |
| [導流終點] | LINE 聊天群 |
| [地址] [營業時間] [服務區域] [運費] [下單截止] | 依店家 |
| [挑選條件與順序] | 1 最新鮮好看 → 2 需要趕快賣 → 當季／常被問／價格有競爭力 |

## 輸入格式（請當事人每天照這個給）
```
照片數張
一行字：[品名] [價格]／[單位]、[品名] [價格]／[單位]…
（選填）產地：…　試吃感受：…　哪樣進比較多：…　快放不住的：…
```
缺產地、缺試吃感受時，先問，不要猜。

## 步驟
1. **挑品項**：依 [挑選條件與順序] 選出最多 [品項上限] 樣。
2. **選主推**：依主推規則（寫在該店的 SKILL.md）選 1 樣。
3. **寫文案**：每個平台一份，精華文字 ≤ [字數上限]，依平台改寫，不同平台不要複製貼上。
4. **圖卡文字**：標題（含勾子）、每樣品名＋價格、結尾導流句。
5. **做圖卡**：用 `ig/` 範本產生（見 `ig/README.md`）。
6. **跑檢查**：`toolbox/copy-qa-checklist.md`。
7. **交回當事人**：文案、圖卡文字、圖卡、檢查結果。agent 不自己發文。

## 交回格式
```
【今日挑選】主推：[品名]（理由：…）／其他：[品名]…
【Threads】…
【FB 在地社團】…
【IG】…
【LINE 聊天群】…
【圖卡文字】標題：… ／品項：… ／結尾：…
【檢查結果】✅/⚠ 逐項列出
```

## 勾子寫法（已驗證可用的類型）
- 問句：「[商品] 買回家，你是馬上吃，還是先放著？」
- 反常識小技巧：「[商品] 先別急著切，多放幾天再削。」（必須是當事人說過的）
- 真實客人故事：「很多人怕 [商品] [缺點]，但這位客人今天回來買了 [數量]。」
- 在地點名：「[地區] 的鄰居，今天 [金額] 想帶 [A] 還是 [B] 回家？」
- 幫客人做決定的組合：「[A] [數量]＋[B] [數量]＝[金額]」
