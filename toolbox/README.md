# Toolbox

可重複使用的工作流程與模板。專案專屬內容放在各自的 skill（例：`.claude/skills/yingzai-fruit-business/`）。

| 檔案 | 用途 |
|---|---|
| `interview-to-skill.md` | 把重複工作訪談成 SKILL.md |
| `daily-post-workflow.md` | 每日商品推薦貼文（多平台） |
| `copy-qa-checklist.md` | 發文前檢查表、禁用詞、字數程式 |
| `festival-campaign-template.md` | 節慶檔期宣傳＋農曆查證 |
| `social-diagnosis.md` | 社群成效診斷 |
| `../ig/README.md` | 圖卡範本使用方式 |
| `../line-order/README.md` | LINE 訂單機器人 |
