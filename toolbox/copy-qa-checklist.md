# 發文前檢查表（文案＋圖卡）

每次發文前逐項打勾，結果一併交給當事人。

## 檢查表
- [ ] 品項、價格和當事人今天給的資料**完全一致**
- [ ] **產地**正確：文字、圖片、商品貼紙三者一致；衝突就問
- [ ] **品名錯字**（建立該店的常見錯字表，例：蜜世界≠密世界）
- [ ] 品牌名稱、群組名稱只用**一個固定寫法**：[品牌名稱]、[群組名稱]
- [ ] 每個平台精華文字 ≤ [字數上限]（用下方程式算，不要目測）
- [ ] 口感描述都來自當事人**親口說過**的
- [ ] 沒有禁用詞（見下）
- [ ] 附上 [地址]、[營業時間]、[導流連結]，且放在該平台正確位置
- [ ] 圖片上的**日期是今天**
- [ ] 節慶日期已用工具查證（見 `festival-campaign-template.md`）
- [ ] 不含個資（客人姓名、臉、地址、電話）

## 通用禁用詞
- 浮誇廣告詞：極品、頂級、絕對好吃、全台最好、保證、必買
- 討粉字眼：速速漲粉、互追、求追蹤
- 未經證實的稀缺：快賣完、剩最後幾個（除非是真的）
- 比價與最低價：最便宜、比別家便宜
- 各店另加：[該店紅線]

## 字數檢查程式
```bash
python3 - <<'PY'
posts = {
  "Threads": "[文案]",
  "FB": "[文案]",
}
LIMIT = 50  # [字數上限]
for k, v in posts.items():
    print(k, len(v), "OK" if len(v) <= LIMIT else "超過")
PY
```
