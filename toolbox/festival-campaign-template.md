# 節慶檔期宣傳模板（含農曆查證）

## 需要替換的欄位
[節日名稱] [國曆日期] [農曆日期] [預訂截止] [品項與價格] [導流終點] [品牌名稱] [地址] [營業時間]

## 1. 先查證日期（不要自己換算農曆）
```bash
cd [暫存資料夾] && npm i lunar-javascript >/dev/null 2>&1
node -e "
const {Solar}=require('lunar-javascript');
for (let d=1; d<=31; d++) { try {
  const s=Solar.fromYmd([年],[月],d), l=s.getLunar();
  console.log([月]+'/'+d, l.getMonthInChinese()+'月'+l.getDayInChinese(), l.getFestivals().join(','), '週'+'日一二三四五六'[s.getWeek()]);
} catch(e){} }"
```
- 閏月的初一、十五同樣要列出。
- 國定假日落在週六時，可能前一天補假形成連假，以政府公告為準。

## 2. 宣傳節奏
| 時間 | 目的 | 文案方向 |
|---|---|---|
| D-2 | 預告 | 「[國曆日期] 是 [農曆日期]，[用途] 準備好了嗎？」 |
| D-1 | 開放預訂＋最後提醒 | 「明天 [農曆日期]，[預訂截止] 前下單…」 |
| D | 當天 | 早安問候＋現場照 |

## 3. 輪播結構（5 張＋結尾卡）
1. 封面勾子：「[農曆日期] [用途] 的 [商品]，你備好了嗎？」＋往右滑
2. 日期表：相關的 2～3 天國曆＋農曆
3. 提醒：只寫通用、確定的事；習俗各地不同，寫「不確定先問 [廟方／長輩]」
4. 可預訂品項＋價格
5. 預訂方式＋截止時間＋[導流 QR]
6. 結尾卡：追蹤＋[導流終點]

範本檔：`ig/jingguo.html`（改最上方設定區即可沿用到其他節日）。

## 4. 拍攝清單
- 擺好的組合（俯拍、自然光）
- 價格牌入鏡
- 挑選、打包的手
- 已預訂的袋子（遮住客人名字）
- 開門的店面（當天用）
