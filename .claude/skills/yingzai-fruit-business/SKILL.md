# 英仔果子行生意專案

> 本文件只收錄店主「小英仔」在訪談中說過的內容。
> 標註「〔待確認〕」的地方是 agent 的理解或委託設計，尚未經小英仔確認，執行時照做，但遇到問題要回頭問。

## Purpose

用最短的時間，把每天的好貨、節慶檔期和宮廟禮籃，以小英仔的口吻推到梓官、岡山、彌陀、永安的在地客人面前，引導他們進入 LINE 聊天群下單，變成實際的客人。

## When to use

- **每天 7:00** 要發「今日新品推薦」時。
- **每月農曆初一、十五的前兩天**，開始準備節慶宣傳時。
- **過年、中秋、清明**等年度大節日前。
- **宮廟提前一週告知需求**、要安排禮籃與送貨時。
- 想開發**神明聖誕禮籃＋賀卡**這個新賽道時。

## Inputs

### 每日新品推薦
- **手機裡剛拍的照片**（04:00 進貨後拍）
- **已經訂好的售價**，小英仔用一行字給，例如：`蜜世界 400／顆、百香果 5 粒 100…`

### 節慶檔期
- 當月農曆初一、十五的國曆日期（用萬年曆或農曆工具查，不靠記憶）
- 當天的品項與售價

### 宮廟訂單
- 廟方提前一週傳來的需求（送貨日、籃數）〔待確認：是否也會指定品項〕
- 當週的進貨品項

### 固定店家資料（每次都要對照）

| 項目 | 內容 |
|---|---|
| 店名 | 英仔果子行 |
| 地址 | 高雄市梓官區通安路 215 號 |
| 營業時間 | 06:00–12:00（04:00 進貨） |
| 送貨 | 梓官、岡山、彌陀、永安，運費 50 元，12:00 前下單當天送〔待確認：12:00〕 |
| 付款 | 現金 |
| LINE 聊天群 | 阿英的聊天群（OpenChat），QR：`ig/assets/line-openchat-qr.jpg` |
| LINE 官方帳號 | 一對一下單、收送貨的地址電話 |
| Threads／IG | @a_yin_fruit |
| 禮籃 | 固定宮廟專用，600 元，5 種水果，由店家送 |

## Steps

### A. 每日新品推薦（目前約 1 小時，目標用 agent 縮短）

1. **04:00 進貨**，回店後拍照。
2. **06:00 開店。**
3. **挑出今天進貨最好的品項，最多 5 樣**（判斷見 Decisions）。
4. **決定主推**（判斷見 Decisions）。
5. **寫文案**：四個平台各寫一份，每份最精華的文字**最多 50 字**，並**依各平台的演算法改寫**。
6. **用 Canva 做圖**：標題、品名、價格。
7. **發文前檢查**（見 Definition of Done）。
8. **7:00 發到四個平台**：Threads、FB（在地社團）、IG、LINE 聊天群。

**agent 要交回給小英仔的東西：**
1. 四個平台各一份文案
2. Canva 用的圖片文字（標題、價格）
3. 直接做好的圖卡
4. 發文前的檢查結果

〔待確認〕agent 不自己發文，由小英仔看過後自己發。

### B. 節慶檔期

1. 查出每月**農曆初一、十五**的國曆日期。
2. **提前兩天**開始宣傳。
3. 高峰是**前一天和當天**。
4. 年度最大檔期：**過年、中秋、清明**。

### C. 宮廟固定訂單與禮籃

1. 廟方**提前一週**透過 LINE 告知需求。
2. 依**當週進貨**搭配，每籃 **5 種水果**，**600 元**，籃數每次不同。
3. 送出前**再挑選一次**。
4. **中午送到**宮廟。

### D. 接單與紀錄

1. 在聊天群發推薦菜單。
2. 客人在群組**留言要幾顆**，或透過 **LINE 官方帳號一對一**下單。
3. 要送貨的客人，**一對一**請對方提供地址和電話。
4. 記錄訂單：目前用**手寫記錄本**；逐步改成由小英仔（或 agent）把訂單填進 **Google 表單**，送出後 **Gmail** 即時通知小英仔。

## Decisions

### 挑品項（最多 5 樣）
- 如果品項**外觀最漂亮、最新鮮**，就**最優先**選（第 1 順位）。
- 如果品項**進比較多、需要趕快賣**，就列為**第 2 順位**。
- 如果品項是**當季、剛上市、別家可能沒有**，可以選。
- 如果品項是**價格最划算、有競爭力**，可以選。
- 如果品項是**客人最近常問**的，可以選。
- 如果超過 5 樣，不要全放，**只留 5 樣**。

### 主推〔待確認：小英仔委託 agent 設計〕
- 如果有一樣是**外觀最漂亮、最新鮮**的，就把它當主推。
- 如果最新鮮的有兩樣以上，就選**需要趕快賣**的那樣。

### 文字與口吻
- 如果要寫文案，就用**小英仔**的口吻：一個在賣水果、分享生活的人。
- 如果文字太像廣告、太浮誇（極品、頂級、絕對好吃），不要用，改成小英仔平常講話的說法。
- 如果文字太長、太文謅謅、不像賣水果的人講話，不要用，改短、改口語。
- 如果一個平台的精華文字超過 50 字，不要發，改到 50 字以內。
- 如果要發到不同平台，不要同一份複製貼上，改成依該平台的演算法改寫。

### 價格
- 如果是一般商品，不要打折、不要寫「最便宜」、不要跟別家比價。
- 如果水果**快放不住**，就**可以便宜賣**。

### 產地與口感
- 如果產地**沒確認過**，不要寫產地。
- 如果水果**沒吃過**，不要寫「很甜」這類口感。

### 其他
- 如果寫到店裡的事，不要提**阿公過世**。
- 如果是 **Threads**，目標是**把流量做大**，再引導到聊天群下單。
- 如果是 **FB**，就發在**在地社團**，引導到聊天群下單。
- 如果客人要送貨，不要在群組問地址電話，改成**一對一**詢問。
- 如果客人不太會用手機，就照舊用**手寫記錄本**；會用的，用表單。

### 視覺
- 如果要做圖，就用小英仔 Canva 設計的配色（米白宣紙底、黑色毛筆字、暖黃、灰藍、水果橘紅）。
- 如果要放文字，就用「**可畫成雲手寫體**」繁體，**一律加粗**。

## Definition of Done

每次發文前，以下全部打勾才算完成：

- [ ] 品項和價格與小英仔今天給的**完全一致**
- [ ] **產地正確**
- [ ] **沒有錯字**
- [ ] 每個平台的精華文字 **≤ 50 字**
- [ ] 附上**地址、營業時間、聊天群連結**
- [ ] 圖片上的**日期是今天**
- [ ] 四個平台的文案、Canva 文字、圖卡、檢查結果**都交給小英仔**

成效的好壞，依序看：
1. **按讚、留言、私訊**：越多越好，而且要**比以往提升**。
2. **變現**：變成實際的客人。
3. **區域**：先吸收**梓官、岡山、彌陀、永安**的客人，做穩在地實體生意，再往其他區域擴散。

## Edge Cases

### 特殊情況
- **客人不太會用手機**：不用表單，維持手寫記錄本。
- **送貨客人**：地址、電話只能一對一取得，不在群組公開。
- **宮廟籃數每次不同**：照廟方當次告知的籃數準備。
- **禮籃在節慶時不一定變多**：禮籃是要新開發的賽道，不能假設節慶就有禮籃訂單。
- **神明聖誕賀卡＋禮籃**：還沒做過，想試；賀卡以加購方式提供，價格 50 元／張還在考慮。
- **快放不住的水果**：可以便宜賣，是「不打折」規則的例外。

### 過去容易犯的錯
小英仔說「每天都在犯錯」。以下是 agent 從過去貼文中看到的〔待確認〕：
- 產地寫錯（紐西蘭蘋果寫成智利蘋果）
- 品名錯字（蜜世界寫成「密世界」）
- 店名、群組名稱不統一（英仔果子行、英仔水果、阿英的聊天群、英仔水果聊天團）
- 把很長的網址直接貼在貼文內文
- 加了「速速漲粉，互追」這類字
