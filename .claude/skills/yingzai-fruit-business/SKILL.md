# 英仔果子行生意專案

> 本文件只收錄店主「小英仔」說過的內容。
> 標註「〔待確認〕」的地方尚未經小英仔確認，執行時照做，但要回頭問。

## Purpose

用最短的時間，把每天的好貨、節慶檔期和宮廟禮籃，以小英仔的口吻推到梓官、岡山、彌陀、永安的在地客人面前，引導他們進入 LINE 聊天群下單，變成實際的客人。

## When to use

- **每天 7:00** 要發「今日新品推薦」時。
- **每月農曆初一、十五的前兩天**，開始準備節慶宣傳時。
- **過年、中秋、清明**等年度大節日前。
- **宮廟指定送達日與籃數**、要安排禮籃與送貨時。
- **每週更換宮廟供桌水果**時。
- 想開發**神明聖誕禮籃＋賀卡**或**散客探病、送禮禮籃**時。

## Inputs

### 每日新品推薦
- **手機裡剛拍的照片**（04:00 進貨後拍）
- **已經訂好的售價**，用一行字給，例如：`蜜世界 400／顆、百香果 5 粒 100…`

### 節慶檔期
- 當月農曆初一、十五的國曆日期（用萬年曆或農曆工具查，不靠記憶）
- 當天的品項與售價

### 宮廟訂單
- 廟方在**中午 12:00 前**，**提前指定送達日與籃數**（不指定品項）
- 當週的進貨品項

### 固定店家資料（每次都要對照）

| 項目 | 內容 |
|---|---|
| 店名 | 英仔果子行 |
| 地址 | 高雄市梓官區通安路 215 號 |
| 營業時間 | 06:00–12:00（04:00 進貨） |
| 送貨 | 梓官、岡山、彌陀、永安，運費 50 元，**中午 12:00 前下單當天送** |
| 付款 | 現金 |
| LINE 聊天群 | 阿英的聊天群（OpenChat），QR：`ig/assets/line-openchat-qr.jpg` |
| LINE 官方帳號 | 一對一下單、收送貨的地址電話 |
| Threads／IG | @a_yin_fruit |
| 系列名稱 | 英仔水果小教室：用在 **IG 輪播圖**與不定期的分享 |
| 禮籃 | **宮廟拜拜用一律 600 元**（固定價，不用再問），5 種水果，由店家送 |
| 供桌水果 | 每週為宮廟更換一次，共 **108 顆**，擺放一週 |

## Steps

### A. 每日新品推薦（目前約 1 小時，目標用 agent 縮短）

1. **04:00 進貨**，回店後拍照。
2. **06:00 開店。**
3. **挑出今天進貨最好的品項，最多 5 樣**（判斷見 Decisions）。
4. **決定主推**（判斷見 Decisions）。
5. **寫文案**：四個平台（含 LINE 聊天群）各一份，**內文 50 字以內（含核心文字、地址、營業時間）**，依各平台規則改寫。
6. **用 Canva 做圖**：標題、品名、價格（見「視覺」：只用 Canva，以小英仔的 Canva 設計為底稿）。
7. **發文前檢查**（見 Definition of Done）。
8. **交給小英仔看過**，由小英仔 **7:00 發**到 Threads、FB 在地社團、IG、LINE 聊天群。

**agent 交回給小英仔的東西（agent 不自己發文，結果一律先給小英仔看）：**
1. 四個平台各一份文案
2. Canva 用的圖片文字（標題、價格）
3. Canva 圖卡（複製小英仔的底稿修改，預覽給小英仔看，同意後才存檔）
4. 發文前的檢查結果

### B. 節慶檔期

1. 查出每月**農曆初一、十五**的國曆日期。
2. **提前兩天**開始宣傳。
3. 高峰是**前一天和當天**。
4. 年度最大檔期：**過年、中秋、清明**。

### C. 宮廟禮籃

1. 廟方在中午 12:00 前，提前指定**送達日與籃數**。
2. 依**當週進貨**搭配品項，每籃 **5 種水果**，**600 元**。
3. 送出前**再挑選一次**。
4. **中午送到**宮廟。

### D. 宮廟供桌水果更換

1. **每週**到宮廟更換供桌上要擺一週的水果。
2. 數量共 **108 顆**。

### E. 接單與紀錄

1. 在聊天群發推薦菜單。
2. 客人在群組**留言要幾顆**，或透過 **LINE 官方帳號一對一**下單。
3. 要送貨的客人，**一對一**請對方提供地址和電話。
4. 記錄訂單：目前用**手寫記錄本**；逐步改成由小英仔（或 agent）把訂單填進 **Google 表單**，送出後 **Gmail** 即時通知小英仔。

## Decisions

### 挑品項（最多 5 樣）
- 如果品項**外觀最漂亮、最新鮮**，就**最優先**選（第 1 順位）。
- 如果品項**進比較多、需要趕快賣**，就列為**第 2 順位**。
- 如果品項是**當季、剛上市、別家可能沒有**，可以選。
- 如果品項是**價格最划算、有競爭力**，可以選。
- 如果品項是**客人最近常問**的，可以選。
- 如果超過 5 樣，不要全放，**只留 5 樣**。

### 主推
- 如果有一樣是**最新鮮**的，就把它當主推。
- 如果最新鮮的有**兩樣以上**，或有品項**需要趕快賣掉**，就把這些都**一起推出去**，想辦法趕快賣完。

### 文字與口吻
- 如果要寫文案，就用**小英仔**的口吻：一個在賣水果、分享生活的人。
- 如果文字太像廣告、太浮誇（極品、頂級、絕對好吃），不要用，改成小英仔平常講話的說法。
- 如果文字太長、太文謅謅、不像賣水果的人講話，不要用，改短、改口語。
- 如果內文**超過 50 字（含核心文字、地址、營業時間）**，不要發，改到 50 字以內。**四個平台都適用，包含 LINE 聊天群。**
- 如果要發到不同平台，不要同一份複製貼上，改成依該平台規則改寫。

### 各平台規則
- 如果有**連結**，不要放在內文，**一律放在留言區**。
- 如果是 **Threads**，**主文不要放連結**。目標是把流量做大，再引導到聊天群下單。
- 如果是 **FB**，不要貼**價目表**，改用**圖卡**呈現；連結放在留言區。FB 發在**在地社團**，引導到聊天群下單。

### 價格
- 如果是一般商品，不要打折、不要寫「最便宜」、不要跟別家比價。
- 如果品項**需要趕快賣掉**，就可以用**組合搭配**（例：蘋果 3 顆＋百香果 5 粒＝200 元），或**便宜 10 元**，讓客人覺得份量變多、價格變便宜，目的是趕快賣完。
- 如果水果**熟度已經偏高**，就可以便宜賣，並寫明「**熟度偏高，今天吃正是最剛好的時候**」。

### 產地與口感
- 如果產地**沒確認過**，不要寫產地。
- 如果水果**沒吃過**，不要寫「很甜」這類口感。

### 拜拜與宮廟
- 如果拜拜的習俗或禁忌**確定**，就照正確的寫。
- 如果**不確定**，不要寫，**先詢問廟方**。

### 客人與隱私
- 如果要寫**客人故事**，就用**化名**，**不露臉**。
- 如果客人要送貨，不要在群組問地址電話，改成**一對一**詢問。
- 如果客人不太會用手機，就照舊用**手寫記錄本**；會用的，用表單。

### 其他
- 如果寫到店裡的事，不要提**阿公過世**。

### 視覺
- 之前選用的風格（酒紅金配色、思源宋體等）**全部停用**；名稱「**英仔水果小教室**」沿用。
- 如果要做圖，就用小英仔 **Canva 設計**的配色（米白宣紙底、黑色毛筆字、暖黃、灰藍、水果橘紅）。
- 如果要放文字，就用 Canva 的「**可畫成雲手寫體**」繁體，**一律加粗**。
- 如果不能用可畫成雲手寫體，就改用**標楷體的粗體**，總之要呈現**毛筆字風格**。
- **圖卡一律在 Canva 製作**，不要用程式自動產生圖片（小英仔已停用 `ig/` 的自動圖卡）。
- 如果要做新圖卡，就用 `copy-design` 複製小英仔的 Canva 設計當底稿，**不要直接改原稿**：
  - 配色與字體範本：`https://canva.link/ggtnfta2r12p2ci`（設計 ID `DAHWA57qFtg`）
  - 版型範本（雙果組合、六宮格價格、聊天群 QR）：`https://canva.link/glpwgraefiym483`（設計 ID `DAHXR5sQQgw`）
- 如果改好了，就先給小英仔看預覽，**小英仔同意後才存檔**。
- 圖卡由「設計部」（Visual Storyteller 角色）負責。

### IG 輪播圖（英仔水果小教室）
- 如果要做 IG 輪播圖，就**每次至少 5 張**。
- 如果要做 IG 輪播圖，就標上系列名稱「**英仔水果小教室**」。
- 在 Canva 製作，結構：封面＋品項＋小技巧＋結尾聊天群 QR。

### 商品照片一律正方形
- 如果圖卡或輪播裡放**商品（樣品）照片**，就裁成**正方形（1:1）**，不要用長方形。
- 這條只管**商品照片本身**，不管整張圖卡或輪播的尺寸。
- 參考範例：10/7「今天想帶哪款回家？」六宮格圖卡，每格商品照片都是正方形。

## Definition of Done

### 交件流程（每次都照做）
1. 寫成 `delivery.json`（格式見 `example_delivery.json`），執行 `python3 check_post.py delivery.json`。
2. 程式檢查不到的項目，人工逐條對照下表。
3. 每一項標 **PASS／FAIL／UNVERIFIED**，附上證據。
4. 有 FAIL 就先自己修正，修完重新檢查。
5. 無法驗證的標 **UNVERIFIED**，寫明缺什麼資訊，**不可假設通過**。
6. 沒有 FAIL 後，才把成品和「交件檢查結果」一起交給小英仔看。全部 PASS 才顯示 **✅ READY TO DELIVER**。

### 驗收標準

1. **成品完整**
   驗證方式：`check_post.py`「成品完整」。
   通過條件：有 Threads、FB、IG、LINE 四份文案＋Canva 文字＋至少 1 張圖卡＋本檢查表。

2. **品項數量與價格正確**
   驗證方式：`check_post.py`「品項數」「價格與輸入一致」；逐項對照小英仔當天給的那一行字。
   通過條件：品項 ≤ 5 樣；每段文字、圖卡上出現的價格都和輸入完全一致（空白不計）。

3. **主推符合規則**
   驗證方式：人工對照小英仔提供的「哪樣最新鮮、哪樣要趕快賣」。
   通過條件：主推是最新鮮的；若最新鮮有兩樣以上或有要趕快賣的，這些都有被推出去。小英仔沒提供新鮮度資訊時標 UNVERIFIED。

4. **產地與口感有來源**
   驗證方式：人工逐句找出處（小英仔的訊息、水果貼紙照片）。
   通過條件：每個產地、每句口感描述（甜、脆、香、多汁）都能指出來源；指不出來的一律刪除。

5. **內文字數 ≤ 50 字（含地址、營業時間）**
   驗證方式：`check_post.py` 逐平台計算字數。
   通過條件：Threads、FB、IG、LINE 聊天群都 ≤ 50 字。

6. **必要資訊齊全且名稱統一**
   驗證方式：`check_post.py`「含地址與營業時間」「名稱統一」。
   通過條件：每份內文都有「梓官區通安路215號」「06:00–12:00」；只出現「英仔果子行」，沒有停用名稱。

7. **連結與平台規則**
   驗證方式：`check_post.py`「內文無連結」「FB 無價目表」；人工確認留言區內容。
   通過條件：所有內文沒有網址；連結列在「留言區」欄；FB 內文價格出現少於 2 次並附圖卡。

8. **沒有禁用內容**
   驗證方式：`check_post.py`「無禁用詞」；人工確認客人故事。
   通過條件：禁用詞 0 個（極品、頂級、絕對好吃、最便宜、比價、互追、阿公等）；客人故事用化名、圖片無客人臉部；拜拜習俗只寫確定的。

9. **沒有錯字與未完成內容**
   驗證方式：`check_post.py`「無錯字與未完成字」。
   通過條件：沒有已知錯字（密世界）；沒有［］、[ ]、○○、TODO、放照片、@你的 等未填字。

10. **圖卡規格與一致性**
    驗證方式：Canva `read-design` 讀元素尺寸與文字；人工比對預覽圖。
    通過條件：每張 1080×1350；圖上的品名、價格、產地與文案一致；日期是今天（台北時間）；配色依 Canva 設計；在 Canva 製作，字體為可畫成雲手寫體加粗（或標楷體粗體）；**IG 輪播 ≥ 5 張**。所有**商品照片框皆為正方形（寬＝高）**。

### 成效（發文後追蹤，不屬於交件驗收）
1. **按讚、留言、私訊**：越多越好，而且要**比以往提升**。
2. **變現**：變成實際的客人。
3. **區域**：先吸收**梓官、岡山、彌陀、永安**的客人，再往其他區域擴散。

## Edge Cases

### 特殊情況
- **客人不太會用手機**：不用表單，維持手寫記錄本。老客人大多是長輩、只有少數會用 LINE，聯繫改用電話或當面。
- **送貨客人**：地址、電話只能一對一取得，不在群組公開。
- **宮廟籃數每次不同**：照廟方當次指定的籃數準備。
- **禮籃在節慶時不一定變多**：禮籃是要新開發的賽道，不能假設節慶就有禮籃訂單。
- **神明聖誕賀卡＋禮籃**：還沒做過，想試；賀卡以加購方式提供，50 元／張還在考慮。
- **散客探病、送禮禮籃**：可以試試看，目前還沒開發。
- **需要趕快賣、熟度偏高的水果**：可以組合、便宜 10 元或便宜賣，是「不打折」規則的例外。

### 過去容易犯的錯（已確認，每次交件都要檢查）
- 產地寫錯：紐西蘭蘋果寫成智利蘋果 → 產地一律對照小英仔訊息或水果貼紙（驗收第 4 項）
- 品名錯字：蜜世界寫成「密世界」→ `check_post.py` 錯字表（驗收第 9 項）
- 店名、群組名稱不統一 → 只用「英仔果子行」「阿英的聊天群」（驗收第 6 項）
- 把很長的網址直接貼在貼文內文 → 連結一律放留言區（驗收第 7 項）
- 加了「速速漲粉，互追」→ 禁用詞（驗收第 8 項）
