# 新訂單通知設定（Google 試算表 + Email）

客人送出訂單後，網站會自動：
1. 在你的 **Google 試算表**新增一列（時間、訂單編號、姓名、電話、送達日、農曆、品項、卡片文字、合計…）。
2. 寄一封 **Email** 給你（手機裝 Gmail App 就會跳通知）。

訂單一定會先存進網站後台；就算 Google 暫時出問題，訂單也不會遺失，後台會標示「Google 通知失敗」。

## 設定步驟（約 10 分鐘，用電腦做）

### A. 建立試算表與腳本
1. 打開 Google 雲端硬碟 → 新增 → Google 試算表，取名「英仔果子行 訂單」。
2. 上方選單：**擴充功能 → Apps Script**。
3. 把編輯器裡原有的程式全部刪掉，貼上專案裡 `docs/google-apps-script.gs` 的全部內容，按存檔。
4. 左側 **專案設定（齒輪）→ 指令碼屬性 → 新增指令碼屬性**，加兩個：
   - `SECRET`：自己想一組長一點的密碼（例如 `gzh-8Kd92xQp`），等一下要填到 Netlify。
   - `NOTIFY_EMAIL`：收通知的 Email，多個用逗號隔開。

### B. 發佈成網頁應用程式
1. 右上角 **部署 → 新增部署作業**，類型選 **網頁應用程式**。
2. 「執行身分」選**我**；「誰可以存取」選**所有人**。
3. 按部署，第一次會要求授權（進階 → 前往…（不安全）→ 允許，因為是你自己的腳本）。
4. 複製部署後給你的 **網頁應用程式網址**（`https://script.google.com/macros/s/…/exec`）。

### C. 填到 Netlify
Site configuration → Environment variables，新增兩個：
- `GOOGLE_SCRIPT_URL`：剛剛複製的網址
- `GOOGLE_SCRIPT_SECRET`：和腳本 `SECRET` 相同的密碼

然後到 Deploys 按 **Trigger deploy**。

### D. 測試
到網站下一張測試訂單 → 試算表應多一列、Email 應收到通知。測完在後台把測試訂單改成「已取消」。

> 提醒：網址和密碼只放在 Netlify 環境變數與你自己的 Google 腳本，不要貼到公開的地方。
