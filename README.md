# 英仔果子行 訂購網站

水果訂購網站：公定版（NT$600）下單、指定送達日期（國曆＋農曆）、配送／自取、卡片文字與包裝、現金付款，訂單推送到店家 LINE，附管理後台。

## 功能
- 下單頁（`/`）：手機優先，日曆同時顯示農曆，初一／初二／十五／十六標示為大月；週一公休（初一、初二、十五、十六照常營業；其他週一特例由後台「特別營業日」每月設定）；日曆標示敬果日、公司拜拜；小量最少提前 3 天、大量最少提前 7 天、不可當天訂。
- 配送僅限高雄市永安、彌陀、岡山、梓官（運費 NT$50），其餘本店自取（免運）；每日接單上限 NT$500,000。
- 後台（`/admin`）：即將到來的大月提醒（含目前訂單量）、每日備貨總表、訂單管理（狀態、是否已收現金）、建立客製化訂單（金額手動輸入）、設定（價格、天數、休息日、國定假日、配送區域、包裝等）。

## 本機執行
```bash
npm install
ADMIN_PASSWORD=你的密碼 npm run dev   # http://localhost:8888 ，後台 /admin
npm test
```

## 部署（Netlify）
1. 連接此 repo，發佈目錄 `public`，函式目錄 `netlify/functions`（已在 `netlify.toml` 設定）。
2. 環境變數：
   - `ADMIN_PASSWORD`（必填，後台密碼）
   - `LINE_CHANNEL_ACCESS_TOKEN`、`LINE_TARGET_ID`（LINE Messaging API 推送；未設定時訂單仍會儲存，後台會顯示推送失敗）
   - `LINE_URL`（客人「私訊 LINE」按鈕的連結，也可在後台設定）
3. 資料存放於 Netlify Blobs。

## 上線前要確認
- 國定假日清單（後台設定，每年更新）、本店地址、LINE 連結。
- 「大量訂購」的份數門檻（預設 10 份）與最多可提前預訂天數（預設 90 天）。
- 包裝選項與加價（預設只有「標準包裝」）。
